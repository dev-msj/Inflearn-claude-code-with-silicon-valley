# 배당 기록 앱 (Dividend Tracker)

보유 종목, 실제로 받은 배당, 수익률 변화를 기록하고, 종목별 배당 지급 일정을 바탕으로 **향후 12개월의 월별 배당 소득을 예측**하는 개인용 웹 앱입니다.

- 백엔드: Django 5.2 (LTS)
- 프론트엔드: Django 템플릿 + CSS
- DB: SQLite (`db.sqlite3`)
- 모든 데이터는 직접 입력합니다(외부 시세 API를 사용하지 않습니다).
- 로그인 없이 혼자 쓰는 앱입니다. 관리자 페이지(`/admin/`)만 Django 계정으로 보호됩니다.

상세 스펙은 [`specs/dividend-tracker-spec.md`](specs/dividend-tracker-spec.md)에 있습니다.

## 사용자 매뉴얼

### 1. 설치

conda env `py312`(Python 3.12)를 사용합니다.

```bash
conda activate py312
pip install -r requirements.txt
python manage.py migrate
```

`migrate`는 처음 한 번만 실행하면 됩니다. 이 명령이 `db.sqlite3` 파일을 만듭니다.

### 2. 실행

```bash
conda activate py312
python manage.py runserver
```

브라우저에서 <http://127.0.0.1:8000/>을 엽니다. 서버를 끄려면 터미널에서 `Ctrl+C`를 누릅니다.

관리자 페이지를 쓰려면 계정을 먼저 만듭니다.

```bash
python manage.py createsuperuser
```

### 3. 화면 구성

| 메뉴 | 주소 | 하는 일 |
|---|---|---|
| 대시보드 | `/` | 총 평가액, 연간 예상 배당, 월 평균 배당, 포트폴리오 수익률, 향후 12개월 월별 예측을 보여 줍니다. |
| 종목 | `/tickers/` | 보유 종목 목록과 종목별 수익률을 보여 줍니다. |
| 종목 상세 | `/tickers/<번호>/` | 한 종목의 지표, 수익률 이력, 배당 기록을 보여 줍니다. |
| 배당 기록 | `/dividends/` | 실제로 받은 배당 목록과 연도별 수령 합계를 보여 줍니다. |
| 관리자 | `/admin/` | Django 관리자 페이지에서 모든 데이터를 직접 편집합니다. |

### 4. 종목 등록하기

**종목 → 종목 등록**에서 아래 항목을 입력합니다.

| 항목 | 설명 | 예시 |
|---|---|---|
| 종목 코드 | 소문자로 입력해도 대문자로 저장됩니다. 같은 코드는 중복 등록되지 않습니다. | `KO` |
| 종목명 | 선택 항목입니다. | `Coca-Cola` |
| 보유 수량 | 소수점 수량도 입력할 수 있습니다. | `50` |
| 평균 매입가 | 원가 수익률 계산에 쓰입니다. | `60` |
| 현재가 | 현재 수익률과 평가액 계산에 쓰입니다. | `70` |
| 1회 주당 배당금 | **연간 배당금이 아니라 한 번 지급될 때의 주당 금액**을 입력합니다. | `0.51` |
| 지급 주기 | 월배당 / 분기배당 / 반기배당 / 연배당 중에서 고릅니다. | 분기배당 |
| 첫 지급 월 | 1년 중 아무 지급 월이나 하나를 입력합니다. 나머지 지급 월은 주기에 따라 자동으로 계산됩니다. | `4` → 1, 4, 7, 10월 |

### 5. 종목 수정과 삭제

- 종목 상세 화면에서 **수정** 또는 **삭제**를 누릅니다.
- 주가가 바뀌면 **현재가**를 수정해 주세요. 그래야 수익률과 평가액이 최신 값으로 계산됩니다.
- 종목을 삭제하면 그 종목의 배당 기록과 수익률 이력도 함께 삭제됩니다.

### 6. 수익률 추적

다음 경우에 그 시점의 가격, 연간 주당 배당금, 수익률이 **수익률 이력**에 한 줄씩 자동으로 기록됩니다.

- 종목을 처음 등록할 때
- 현재가, 1회 주당 배당금, 지급 주기 중 하나라도 바꿔서 저장할 때

보유 수량이나 종목명만 바꾼 경우에는 이력이 남지 않습니다. 주가를 정기적으로(예: 매주) 갱신하면 수익률 변화를 추적할 수 있습니다.

### 7. 배당 기록 남기기

**배당 기록 → 기록 추가**에서 종목, 지급일, 주당 지급액을 입력합니다.

- **수량**을 비워 두면 그 종목의 현재 보유 수량이 자동으로 들어갑니다.
- 배당을 받은 뒤에 수량이 바뀌었다면, 지급 당시의 수량을 직접 입력해 주세요.
- 목록 위쪽에 연도별 실제 수령 합계가 표시됩니다.

### 8. 계산 방식

| 지표 | 계산식 |
|---|---|
| 연간 주당 배당 | 1회 주당 배당금 × 연간 지급 횟수 |
| 연간 예상 배당 | 연간 주당 배당 × 보유 수량 |
| 평가액 | 현재가 × 보유 수량 |
| 현재 수익률 | 연간 주당 배당 ÷ 현재가 |
| 원가 수익률 | 연간 주당 배당 ÷ 평균 매입가 |
| 포트폴리오 수익률 | 전체 연간 예상 배당 ÷ 전체 평가액 |
| 월 평균 배당 | 연간 예상 배당 ÷ 12 |

**월별 예측**은 이번 달부터 12개월 동안 각 달에 지급 월이 해당하는 종목의 `1회 주당 배당금 × 보유 수량`을 더한 값입니다.

예를 들어 O(월배당, 1회 0.2635, 100주)와 KO(분기배당 1·4·7·10월, 1회 0.51, 50주)를 보유하면 다음과 같습니다.

- 매월: O 26.35
- 1·4·7·10월: O 26.35 + KO 25.50 = 51.85
- 12개월 합계: 26.35 × 12 + 25.50 × 4 = 418.20

현재가나 매입가가 0이면 수익률은 `-`로 표시됩니다.

### 9. 주의 사항

- **통화를 구분하지 않습니다.** 원화 종목과 달러 종목을 함께 입력하면 금액이 그대로 더해집니다. 한 가지 통화로 맞춰서 입력해 주세요.
- **지급 간격이 일정한 종목만 정확히 예측됩니다.** 분기배당은 3개월, 반기배당은 6개월 간격으로 계산됩니다. 지급 월이 불규칙한 종목은 예측이 실제와 다를 수 있습니다.
- 예측은 현재 입력된 배당금과 수량이 앞으로도 유지된다고 가정합니다. 배당 증액, 감액, 특별배당은 반영되지 않습니다.
- 데이터는 모두 `db.sqlite3` 파일 하나에 저장됩니다. 백업하려면 이 파일을 복사해 두세요.
